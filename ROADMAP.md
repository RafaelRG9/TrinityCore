# Project Roadmap

**Phase 1: Foundation (Visuals, AH Bot, Configs)**
* Initial setup and configuration.
* Setting up Auction House Bot.
* Adjusting world configuration (Auto-Learn, etc.).
* Visual enhancements.

**Phase 2: Global Systems (Auto-Scaling & Portable NPC)**
* Implementing global auto-scaling systems for levels/stats.
* Creating a portable NPC system for utility anywhere.

**Phase 3: The Companion (SWTOR-style Scripted Guardian)**
* Implementing a scripted guardian companion akin to SWTOR.
* Complex behaviors and persistent interactions.

**Phase 4: The Overhaul (Class Kits & Boss Mechanics)**
* Overhauling class kits and abilities.
* Customizing and enhancing boss mechanics.
